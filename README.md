# Banking Customer & Transaction Analytics

End-to-end banking analytics project using PostgreSQL, Python, Pandas, NumPy, Power BI and DAX.

## Project Metrics
- 2,500 customers
- 120,000 transactions
- Total transaction value: approximately ₹355.30M
- Average transaction value: approximately ₹2.96K
- 466 customers with no transactions
- Segments: Mass Market, Affluent, High Net Worth, Student

## Business Questions
- How is the customer base distributed across segments?
- Which segments contribute the most transaction value?
- Which categories generate the highest value and volume?
- Which channels are used most?
- How many customers are inactive?
- Which customers have high activity and monetary value?
- What do RFM segments indicate?

## Key Findings
Mass Market is the largest customer segment with 1,523 customers. Salary has the highest total transaction value, while Transfer and Shopping have the highest transaction volumes. Mobile App has the highest total transaction value among the analyzed channels. Debit transaction value is higher than Credit transaction value.
